2. ROSANET MODEL ARCHITECTURE DETAILS
--------------------------------------------------------------------------------
- Input Tensor per Patient: 8 physical recording branches, each shape (64, 626, 1)
- Feature Extraction Backbone (RosaNet):
  * Multi-Path Receptive Field Convolutional Block: 4 parallel paths (3x3, 5x5, 7x7, 1x1 Conv2D)
    capturing fine acoustic clicks, systolic ejection murmurs, and diastolic rumbles.
  * Intermediate & Deep Conv stages with Batch Normalization, ReLU, MaxPool(2,2), Dropout.
  * Split-Self-Attention: Feature channel splitting, non-linear projection gating, and feature modulation.
  * Hybrid Global Pooling (GAP + GMP) -> 128-D Feature Embedding.
- Explicit Attention Mechanism:
  * Cardiac Spatial/Temporal Feature Attention: Computes importance weights alpha in [0, 1]
    via gating network to weight clinically salient cardiac acoustic patterns.
  * Flow: INPUT FEATURES -> ATTENTION -> LEARNED IMPORTANCE WEIGHTS -> WEIGHTED FEATURES.
- Dynamic Decision Fusion:
  * Generates 8 branch-level disease predictions [P(N), P(AS), P(AR), P(MR), P(MS)].
  * Dynamically computes branch diagnostic confidence across valve sites for each disease class.
  * Aggregates weighted decisions and passes through a non-linear clinical interaction refinement head.
- Final Output:
  * Shape: (B, 5) -> Multi-label disease probabilities [P(N), P(AS), P(AR), P(MR), P(MS)] in [0, 1]^5.
  * Multi-label binary cross-entropy formulation with sigmoid activations.
